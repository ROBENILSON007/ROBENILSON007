# Olá, eu sou Robenilson 👋

**Desenvolvedor PHP/Web** e **fundador do DentalPrice** — uma plataforma SaaS que ajuda clínicas e consultórios odontológicos a precificar seus procedimentos com base no custo real (insumos, tempo clínico, estrutura e impostos), em vez de "achismo".

---

### 🦷 Sobre o DentalPrice

Construí o DentalPrice do zero: da estrutura da clínica (salas, profissionais, horas de funcionamento) ao custo de cada insumo, o sistema calcula o custo real de qualquer procedimento e sugere o preço de venda ideal, considerando impostos, comissão, taxa de cartão e margem de lucro desejada.

- 🏗️ Arquitetura multi-tenant, construída com **Slim Framework 4** + **Twig** + **MySQL**
- 💳 Integração com gateway de pagamento (**Asaas**) para assinaturas
- 📊 Geração de relatórios em PDF/Excel para o dono da clínica
